# TaskTrail — TimeBucks Referral Landing Site

Independent, mobile-responsive TimeBucks referral acquisition microsite.

## Public path

Expected GitHub Pages URL when the host repository publishes main/root:

https://iederees-create.github.io/affiliate-landing-page/timebucks/

Repository: https://github.com/iederees-create/affiliate-landing-page/tree/main/timebucks

## Referral destination

https://timebucks.com/?refID=217489180

All commission-generating signup CTAs use the same direct destination, with 'sponsored nofollow noopener' on external links. Affiliate disclosures appear on every relevant page. Promotional bonuses and earnings are not guaranteed.

## Files

- index.html — landing page, task types, earnings *example* calculator, FAQs
- styles.css — self-contained responsive styling
- app.js — menu, calculator, copy/share buttons, campaign URL builder
- guide.html — getting-started education
- promote.html — optional social outreach/share assets and UTM link builder
- privacy.html — affiliate disclosures and privacy policy notes

## Deployment

The repository **already contained a different affiliate website**. TaskTrail was added under /timebucks/ without replacing its files. GitHub Pages settings for the parent repo must use Deploy from branch / main / (root) for the URL above to work. If Pages is not enabled, go to Repo > Settings > Pages and select that source. It can take a short time to publish.

## Analytics and attribution

TimeBucks itself tracks actual referral eligibility and commissions. Static GitHub Pages does not receive TimeBucks account activity or aggregate conversion reporting. The source-tagged landing links can be measured only after attaching consent-aware analytics (e.g. privacy-friendly analytics) to the site. No third-party traffic analytics currently run.

## Safety and compliance

No guaranteed earnings claims. No fake testimonials, fabricated payout results, self-referral, forced clicks, duplicate accounts or spam. Check TimeBucks' rules before launching campaigns. Do not publish secrets or API keys to GitHub Pages.

## Maintenance

Review program commission rules and current platform information periodically, and update the privacy/disclosures when adding third-party services.
